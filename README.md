# 행정 수수료·과태료 일괄 관리 AI 비서

## 문제
행정 수수료 및 과태료 정보가 여러 기관과 채널에
분산되어 있어 시민이 납부 일정과 금액을 관리하기 어렵다.

## Solution
행정 고지서를 AI가 분석하여
기관, 금액, 납부기한 등의 정보를 자동으로 추출하고
하나의 대시보드에서 통합 관리한다.

## Core Features
1. 행정 고지서 업로드
2. AI 정보 자동 추출
3. 납부 대시보드
4. AI 납부 일정 비서

## Tech
Python / Streamlit / LLM / SQLite / Docker / Naver Cloud
