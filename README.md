# 행정 수수료·과태료 일괄 관리 AI 비서

## 문제
행정 수수료 및 과태료 정보가 여러 기관과 채널에
분산되어 있어 시민이 납부 일정과 금액을 관리하기 어렵다.

## Solution
행정 고지서를 AI가 분석하여
기관, 금액, 납부기한 등의 정보를 자동으로 추출하고
하나의 대시보드에서 통합 관리한다.

## Core Features
1. 행정 고지서 업로드
2. AI 정보 자동 추출
3. 납부 대시보드
4. AI 납부 일정 비서

## Tech
Python / Streamlit / Gemini API / SQLite
(Docker · Naver Cloud 배포는 예정 단계이며 아직 구성되어 있지 않습니다.)

---

## 현재 구현 단계: 추출된 텍스트 → Gemini API → 검증된 JSON → SQLite 저장·목록·상세조회·납부 상태 관리

### 지원 기능
- PDF 파일 업로드 (텍스트 기반 PDF) 및 텍스트 직접 입력
- **암호(비밀번호) PDF 지원**: 열기 비밀번호가 설정된 PDF를 원본 그대로 업로드 가능
- **분석 페이지 선택**: 기본 첫 페이지 추출, 여러 페이지 PDF에서 다른 페이지 선택 가능
- **AI 정보 추출**: 추출된 `notice_text`를 Gemini API로 전송하여 고지서 핵심 정보를 구조화(JSON)
- **SQLite 저장 및 조회**: 분석 결과를 저장하고, 저장된 고지서 목록·상세정보·다가오는 납부기한을 확인
- **납부 완료 표시**: 상세 화면의 "납부 완료로 표시" 버튼 → 확인 단계를 거쳐 상태를 `납부완료`로 변경하고 처리 일시를 기록
- **미납 복원**: 납부완료 고지서의 "미납으로 되돌리기" 버튼으로 상태를 `미납`으로 되돌리고 처리 일시를 제거
- **삭제**: "삭제" 버튼 → "삭제 확인"을 눌러야 실제로 삭제 (되돌릴 수 없음)
- **납부완료 항목 보기**: 목록 상단의 "납부완료 고지서도 보기" 체크박스로 완료 항목까지 표시 (기본은 미납만)
- **AI 비서**: 저장된 고지서 데이터를 기준으로 자연어 질문에 답변

### AI 비서
다음 5가지 의도를 인식하며, 표현이 조금 달라도 이해합니다.

| 의도 | 예시 질문 |
|---|---|
| `this_week` | 이번 주에 내야 할 게 있어? |
| `this_month` | 이번 달에 납부할 고지서 보여줘 |
| `monthly_total` | 이번 달 납부 예정 금액은? |
| `nearest_due` | 가장 가까운 납부기한은? |
| `list_all` | 미납 고지서 전체 목록 보여줘 |

위 의도에 해당하지 않으면 `unknown`으로 분류되어 안내 문구를 반환합니다.

- **답변 기준**: SQLite 조회, 금액 합계, 날짜 계산, 답변 문장 생성은 **모두 로컬 Python에서** 수행하며 저장된 고지서 데이터만 사용합니다. 상태가 `미납`이 아니거나 납부기한이 없는 고지서는 날짜 기반 답변에서 제외됩니다. 날짜는 **앱이 실행되는 서버의 로컬 시간대**를 따릅니다(별도 타임존 변환을 하지 않습니다).
- **외부 전송 범위 (AI 비서)**: Gemini API에는 **사용자가 입력한 질문 텍스트만** 전송하며, 용도는 의도 분류뿐입니다. **DB 조회 결과를 요청에 추가하지 않으므로** 저장된 고지서명·발급 기관·금액·납부기한·납부방법은 전송되지 않습니다. 이 동작은 `test_assistant_no_bill_data.py`가 전송 payload를 직접 검사해 강제합니다.
  다만 **사용자가 질문 문장에 직접 입력한 내용은 질문과 함께 그대로 전송**되므로, 개인정보를 질문에 적으면 외부로 나갑니다.
- **오류 처리**: API 키 누락, 인증 실패(401·403), 모델 접근 불가(404), 사용량 초과(429)는 숨기지 않고 `GeminiError`로 전파되어 해당 안내 문구를 표시합니다. 일시적 혼잡(408·500·502·503·504)과 타임아웃·연결 실패는 SDK 재시도가 소진된 뒤 `GeminiBusyError`로 "현재 AI 서버가 혼잡합니다. 잠시 후 다시 질문해 주세요."를 표시합니다. **응답 형식 문제**(빈 응답, 잘못된 JSON, 목록에 없는 의도)일 때만 `unknown`으로 처리해 규칙 기반 안내 문구로 대체합니다.
- **미지원**: 실제 납부(결제), 저장된 고지서 내용 수정, 법률·행정 판단은 제공하지 않습니다.

### 데이터 저장
- **저장 위치**: `data/bills.db` (SQLite, 테이블 `bills`) — 폴더가 없으면 앱이 자동 생성하며 Git에는 커밋되지 않습니다.
- **저장하는 컬럼**: `id`, `title`(고지서명), `agency`(발급 기관), `amount`(금액), `due_date`(납부기한), `payment_method`(납부방법), `status`(`미납` 또는 `납부완료`), `paid_at`(납부 처리 일시), `created_at`(저장 시각)
- **시각 형식**: `created_at`과 `paid_at`은 `datetime.datetime.now().isoformat(timespec="seconds")` 결과이므로 **UTC가 아니라 서버 로컬 시간** 기준의 초 단위 ISO-8601 문자열입니다.
- **저장하지 않는 정보**: PDF 원본 파일, 추출된 `notice_text`, PDF 비밀번호, API 키
- **계좌번호**: 계좌번호를 담는 전용 컬럼이 없고, 추출 지침에서도 실제 계좌번호를 반환하지 않도록 지시하고 있습니다. 다만 이는 프롬프트 수준의 제약이므로 계좌번호가 결코 저장되지 않는다고 보장하지는 않습니다. `payment_method` 등에 계좌 형태의 문자열이 포함될 가능성은 남아 있으니 저장된 내용을 확인하세요.

### 알려진 제한 사항
- **OCR 미지원**: PyMuPDF의 텍스트 레이어만 읽으며 OCR 라이브러리나 이미지 인식 경로가 없습니다.
- **이미지·스캔 PDF**: 텍스트 레이어가 없으면 "선택한 페이지에서 텍스트를 찾지 못했습니다. 이미지 또는 스캔 페이지일 수 있습니다." 오류가 표시됩니다. 다른 페이지를 선택하거나 "텍스트 직접 입력"을 이용하세요.
- **표·다단 구성**: 복잡한 레이아웃에서는 읽기 순서가 완벽하지 않을 수 있습니다.
- **입력 크기 제한**: PDF 업로드는 최대 10 MB, AI 추출에 전달하는 텍스트는 최대 20,000자입니다.
- **API 사용량 제한과 재시도**: 재시도는 `services/gemini_client.py`의 `create_client()`가 설정하는 공유 클라이언트 옵션에 따라 google-genai SDK가 수행합니다. 대상 상태 코드는 `TRANSIENT_STATUS_CODES = (408, 500, 502, 503, 504)`이며, `attempts=3`(최초 요청 포함), `initial_delay=1.0`, `exp_base=2.0`이므로 대기 시간은 약 1초 → 2초입니다(정확한 간격과 지터는 SDK 구현을 따릅니다). 사용량 초과(HTTP 429)는 **재시도 대상에서 제외**되어 즉시 "API 사용량이 초과되었거나 요청이 제한되었습니다."를 안내합니다. 이 정책은 AI 정보 추출과 AI 비서에 동일하게 적용됩니다. **저장소의 테스트는 이 재시도 동작을 검증하지 않습니다** — 가짜 SDK를 주입해 오류 분기만 확인하므로 실제 요청 횟수와 대기 시간은 검증 범위 밖입니다. API 요금과 한도는 사용자 계정 조건에 따릅니다.
- **외부 전송 (AI 정보 추출)**: "AI로 고지서 분석"을 클릭하면 추출된 고지서 텍스트 전문이 Google Gemini API로 전송됩니다. 구조화 추출에 필요한 동작이며 사용자가 직접 실행할 때만 발생합니다.
- **비밀번호 보안**: PDF 비밀번호는 현재 세션에만 유지되며 저장되지 않습니다.
- **수정 미지원**: 저장된 고지서 내용을 편집하는 기능은 없습니다. 잘못 저장한 경우 삭제 후 다시 등록하세요.
- **타임존**: 별도의 타임존 처리가 없어 앱이 실행되는 서버의 로컬 시간대를 따릅니다.
- **배포**: `Dockerfile`이 비어 있어 현재 컨테이너 빌드는 불가능합니다.

### 환경 변수 설정
프로젝트 루트의 `.env.example`을 복사해 `.env`를 만들고 실제 값을 채웁니다. `.env`는 `.gitignore`에 등록되어 커밋되지 않습니다.

```env
# 필수
GEMINI_API_KEY=발급받은_API_키

# 선택 — 지정하지 않으면 코드 기본값 gemini-3.6-flash 를 사용합니다.
GEMINI_MODEL=gemini-3.6-flash
```

### 설치 및 실행

> 이 저장소에는 가상환경 폴더가 포함되어 있지 않으므로 처음 한 번은 직접 생성해야 합니다.
> `py -3.13`으로 버전을 명시하는 이유는, free-threading 빌드(`3.13t`)에서는 `pymupdf` 설치가 실패하기 때문입니다.

**Windows PowerShell**

```powershell
py -3.13 -m venv .myenv
.\.myenv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env    # 이후 .env 안의 키를 실제 값으로 교체
python -m streamlit run app.py
```

실행 정책 때문에 `Activate.ps1`이 차단되면 활성화 없이 아래처럼 직접 실행할 수 있습니다.

```powershell
.\.myenv\Scripts\python.exe -m streamlit run app.py
```

**Git Bash**

```bash
py -3.13 -m venv .myenv
source .myenv/Scripts/activate
python -m pip install -r requirements.txt
cp .env.example .env           # 이후 .env 안의 키를 실제 값으로 교체
python -m streamlit run app.py
```

### 테스트

실제 API를 호출하지 않는 독립 실행 스크립트입니다. (pytest 불필요)

```bash
./.myenv/Scripts/python.exe test_assistant_no_bill_data.py   # 고지서 데이터 외부 전송 여부 검증
./.myenv/Scripts/python.exe test_pay_feature.py              # 납부 상태 관리 검증
```

`test_assistant_no_bill_data.py`의 검증 범위:

- **검증함** — Gemini 호출 횟수와 전송 내용, 오류 분기(`GeminiError` / `GeminiBusyError` / `unknown` 안내), 테스트가 바꾼 전역 상태(`_DB_PATH`·`_DB_DIR`·환경변수·`sys.modules`)가 같은 프로세스 안에서 원래대로 복원되는지.
- **검증하지 않음** — SDK의 실제 재시도 횟수·대기 시간, 실제 네트워크 동작. google-genai와 httpx, dotenv를 모두 가짜 모듈로 교체하므로 실제 `.env`나 API 키도 읽지 않습니다.

### 수동 확인 절차
1. 브라우저에서 Streamlit 앱이 열리면 "PDF 업로드"를 선택하고 텍스트가 포함된 PDF를 업로드합니다.
2. "텍스트 확인" 버튼을 클릭하여 추출된 텍스트를 확인합니다.
3. 비밀번호가 설정된 PDF를 업로드하면 비밀번호 입력란이 나타납니다. 비밀번호를 입력하고 "PDF 열기"를 클릭합니다.
4. 여러 페이지 PDF에서는 "다른 페이지 선택" 영역에서 원하는 페이지를 선택합니다.
5. "텍스트 직접 입력"으로 전환하여 고지서 내용을 직접 입력하고 결과를 확인합니다.
6. 빈 입력, 이미지 PDF, 손상된 파일, 잘못된 비밀번호 등으로 오류 메시지가 올바르게 표시되는지 확인합니다.
7. 목록에서 고지서를 선택해 "납부 완료로 표시" → "확인"을 누르고, 제목에 취소선이 생기며 목록에서 사라지는지 확인합니다.
8. "납부완료 고지서도 보기"를 체크해 해당 항목을 다시 찾은 뒤 "미납으로 되돌리기"로 상태가 복원되는지 확인합니다.
9. "삭제" → "삭제 확인"으로 고지서가 목록에서 제거되는지 확인합니다.
