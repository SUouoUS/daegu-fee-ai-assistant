# 행정 수수료·과태료 일괄 관리 AI 비서

## 문제
행정 수수료 및 과태료 정보가 여러 기관과 채널에
분산되어 있어 시민이 납부 일정과 금액을 관리하기 어렵다.

## Solution
행정 고지서를 AI가 분석하여
기관, 금액, 납부기한 등의 정보를 자동으로 추출하고
하나의 대시보드에서 통합 관리한다.

## Core Features
1. 행정 고지서 업로드
2. AI 정보 자동 추출
3. 납부 대시보드
4. AI 납부 일정 비서

## Tech
Python / Streamlit / LLM / SQLite / Docker / Naver Cloud

---

## 현재 구현 단계: 추출된 텍스트 → Gemini API → 검증된 JSON 출력

### 지원 기능
- PDF 파일 업로드 (텍스트 기반 PDF) 및 텍스트 직접 입력
- **암호(비밀번호) PDF 지원**: 열기 비밀번호가 설정된 PDF를 원본 그대로 업로드 가능
- **분석 페이지 선택**: 기본 첫 페이지 추출, 여러 페이지 PDF에서 다른 페이지 선택 가능
- **AI 정보 추출**: 추출된 `notice_text`를 Gemini API로 전송하여 고지서 핵심 정보를 구조화(JSON)

### 알려진 제한 사항
- **OCR 미지원**: 스캔본·이미지 PDF에서는 텍스트를 추출할 수 없습니다.
- **표·다단 구성**: 복잡한 레이아웃에서는 읽기 순서가 완벽하지 않을 수 있습니다.
- **비밀번호 보안**: 비밀번호는 현재 세션에만 유지되며 저장되지 않습니다.
- **외부 전송 및 요금**: "AI로 고지서 분석" 클릭 시 추출된 텍스트가 Google Gemini API로 전송됩니다. API 사용량과 요금은 사용자 계정 조건에 따릅니다.
- **DB 미저장**: 이번 단계는 화면 출력까지만 진행되며, 실제 데이터베이스 저장은 구현되지 않았습니다.

### 환경 변수 설정
앱 실행 전, 프로젝트 루트 디렉토리에 `.env` 파일을 만들고 Gemini API 키를 설정해야 합니다. (공식 안정화 모델인 `gemini-2.5-flash` 사용)
```env
GEMINI_API_KEY=당신의_실제_API_키
GEMINI_MODEL=gemini-2.5-flash
```

### 설치 및 실행

```powershell
# 의존성 설치
.\myenv\Scripts\python.exe -m pip install -r requirements.txt

# 앱 실행
.\myenv\Scripts\python.exe -m streamlit run app.py
```

### 수동 확인 절차
1. 브라우저에서 Streamlit 앱이 열리면 "PDF 업로드"를 선택하고 텍스트가 포함된 PDF를 업로드합니다.
2. "텍스트 확인" 버튼을 클릭하여 추출된 텍스트를 확인합니다.
3. 비밀번호가 설정된 PDF를 업로드하면 비밀번호 입력란이 나타납니다. 비밀번호를 입력하고 "PDF 열기"를 클릭합니다.
4. 여러 페이지 PDF에서는 "다른 페이지 선택" 영역에서 원하는 페이지를 선택합니다.
5. "텍스트 직접 입력"으로 전환하여 고지서 내용을 직접 입력하고 결과를 확인합니다.
6. 빈 입력, 이미지 PDF, 손상된 파일, 잘못된 비밀번호 등으로 오류 메시지가 올바르게 표시되는지 확인합니다.
